# E-MART – Ex 10: Server-side app using Node.js HTTP module

No packages needed.

## Run on your laptop
```bash
node local.js
```
Open http://localhost:3000 and try `/`, `/home`, `/products`, `/about` and any wrong URL (404).

## Deploy
Push to GitHub → import the repo in Vercel → Deploy. `vercel.json` sends every URL to `api/index.js`.
